## How a session works

1. Tell Claude: *"Statistics session — I just watched the Unit N videos"* (or "start where
   we left off").
2. Claude reads `tutor-protocol.md` + `tracker.md`, quizzes due reviews first, then new
   material — **one question at a time**, explaining every answer.
3. Wrong/unsure answers get logged and re-asked: same session → next session → ~1 week
   later, until mastered (3 correct on different days).
4. Claude updates `tracker.md` and pushes, so progress survives between sessions.

## Quick start (before class begins July 1)

Watch Khan Academy's "Study design" unit and the "Summarizing quantitative data" unit
(links in `study-guide.md`, Units 1–2), then start a quiz session. Banking Units 1–3
before the course starts buys slack for the brutal weeks 4–6 (CLT, confidence intervals,
hypothesis testing).
